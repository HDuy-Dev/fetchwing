Fetchwing

A lightweight API client and response mocks, right inside Chrome DevTools.

  • Paste cURL from the Network tab, or import a file of commands, then send.
  • Collections, folders, open tabs and quick search.
  • Environments with {{variables}}; secret values stay on your device.
  • Mocks: pages get the response you set for the same method and URL, even with DevTools closed.
  • Optional Google Drive sync to one file in your own Drive.

Get it from the Chrome Web Store (link to come once it is published), or load it unpacked from GitHub.

# Body Tab Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Native execution in one session.

**Goal:** Make the Body tab's type picker, blank rows, tab badge and hints unambiguous.

**Architecture:** Copy and rules that can be tested without a DOM go in `src/lib/body-view.js`; `src/panel/request-editor.js` renders them; styles in `src/panel/panel.css`.

**Tech Stack:** Vanilla ES modules, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-26-body-tab-design.md`

## Global Constraints

- No change to the data model or to how requests are sent.
- UI copy in English, exactly as in the spec. Only existing `panel.css` tokens; dark and light.

## Review Focus

- Switching modes back and forth keeps `raw` and `fields`.
- Typing in a blank row keeps the caret.
- Arrow keys move through the type picker without losing focus.
- Changing the method shows or hides the warning at once.
- Narrow panel: the picker wraps, no horizontal scroll.

(DOM behaviour; checked by hand in the browser.)

# Environment Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Environment mở thành tab cạnh tab request, dropdown chọn env có tìm kiếm, sidebar có ô lọc và thao tác hover.

**Architecture:** `state.openTabs` giữ lẫn id request và id env; loại tab suy ra từ workspace. Logic thuần nằm trong `src/lib/` và test bằng `node:test`; DOM nằm trong `src/panel/`, kiểm bằng trình duyệt. Nội dung dialog cũ chuyển thành view trong vùng chính.

**Tech Stack:** Chrome extension MV3, ES modules thuần, không thêm dependency, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-27-env-tabs-design.md`

## Global Constraints

- Không đổi mô hình dữ liệu, mutation hay đồng bộ (`model.js`, `sync-merge.js` giữ nguyên).
- Không mất giá trị đang gõ; giá trị secret không bị đồng bộ.
- Chữ trên UI là tiếng Anh, đúng như spec: `Search`, `No Environment`, `Create new environment`, `No matches`, `Set active`, `Active`, `Duplicate`, `Delete`, `Name can't be empty`.
- Màu chỉ dùng token sẵn có trong `panel.css`; chạy cả dark, light, panel hẹp.
- Nút chỉ có icon phải có `aria-label` và tooltip (dùng `iconButton`).
- Chưa làm: xem nhanh biến, tìm trong bảng biến, import/export, Share, Fork.

## Review Focus

1. Gõ rồi đổi tab, đổi section hoặc đóng tab trong 300ms: giá trị vẫn được lưu.
2. Panel vẽ lại sau chính lần lưu của mình: focus và con trỏ trong bảng biến không đổi (`sameEnv`, Task 2).
3. Xoá env đang mở tab và còn chữ chờ lưu: tab đóng, không hiện toast "That item no longer exists", chuyển sang tab bên cạnh (`pruneTabs`, Task 1).
4. `fw.tabs` / `fw.selected` cũ hoặc trỏ tới env đã xoá: panel mở bình thường, id chết bị bỏ (Task 1).
5. Gõ trong ô lọc sidebar hoặc ô Search khi sync cập nhật workspace: giữ nguyên chữ lọc và focus (Task 3, 4).

### Task 1: Mô hình tab

**Files:**
- Create: `src/lib/tab-model.js`
- Test: `tests/tab-model.test.js`

**Interfaces:**
- Produces:
  - `tabKind(ws, id): 'request' | 'env' | null` (null nếu không tồn tại, đã xoá, hoặc là folder/collection)
  - `insertTab(ids, id, afterId): string[]` (đã có thì trả nguyên mảng; `afterId` không có trong mảng thì thêm vào cuối)
  - `pruneTabs(ws, ids, selectedId): { ids: string[], selectedId: string | null }`

- [ ] **Step 1: Viết test**

```js
import test from 'node:test';
import assert from 'node:assert/strict';
import { tabKind, insertTab, pruneTabs } from '../src/lib/tab-model.js';

const ws = {
  items: { r1: { type: 'request' }, r2: { type: 'request' }, f: { type: 'folder' }, gone: { type: 'request', deleted: true } },
  environments: { e1: {}, dead: { deleted: true } },
};

test('tabKind knows requests and environments only', () => {
  assert.deepEqual(['r1', 'e1', 'f', 'gone', 'dead', 'nope', null].map(id => tabKind(ws, id)),
    ['request', 'env', null, null, null, null, null]);
});

test('insertTab opens next to the given tab, once', () => {
  assert.deepEqual(insertTab(['a', 'b'], 'e', 'a'), ['a', 'e', 'b']);
  assert.deepEqual(insertTab(['a', 'b'], 'e', null), ['a', 'b', 'e']);
  assert.deepEqual(insertTab(['a', 'b'], 'b', 'a'), ['a', 'b']);
});

test('pruneTabs drops dead tabs', () => {
  assert.deepEqual(pruneTabs(ws, ['r1', 'dead', 'e1', 'gone', 'nope'], 'e1'), { ids: ['r1', 'e1'], selectedId: 'e1' });
});

test('pruneTabs moves a dead selection to the next tab, else the previous', () => {
  assert.equal(pruneTabs(ws, ['r1', 'dead', 'r2'], 'dead').selectedId, 'r2');
  assert.equal(pruneTabs(ws, ['r1', 'dead'], 'dead').selectedId, 'r1');
  assert.equal(pruneTabs(ws, ['dead'], 'dead').selectedId, null);
});

test('pruneTabs keeps a selected folder', () => {
  assert.equal(pruneTabs(ws, ['r1'], 'f').selectedId, 'f');
});
```
